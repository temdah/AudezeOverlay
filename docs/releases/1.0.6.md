- **Try Audeze Overlay on Linux.** Experimental Wayland support brings the overlay, headset controls, EQ presets, tray icon and desktop shortcuts to compatible desktops such as KDE Plasma and Sway.
- **Linux downloads are now on the release page.** Choose a Flatpak bundle or a Linux archive with an install script. Both need a host udev rule for headset access; follow the Linux setup guide below.
- **Windows downloads stay familiar.** Keep using the recommended installer or portable ZIP. Linux packages appear in their own clearly labeled section, with one checksum file covering all downloads.

Linux is experimental and may contain bugs. Contributor testing covers the original Maxwell with its Xbox dongle on Fedora/KDE Plasma. Other headset variants and desktops remain unverified on Linux; GNOME and X11 are not supported. See the setup guide for the hardware evidence and limitations.
